# 술술 첫잔

술을 처음 만나는 사람을 위한 **술 안내 사이트 데모**입니다. 3문항 퀴즈, 술 타로, 칵테일 16종, 술 종류 12종, 입문자 추천 12병이 들어 있습니다.

> 이 사이트는 술을 판매하지 않고 고르는 법만 안내합니다. 상품명과 가격은 참고용 예시이며 결제와 주문 기능은 없습니다. 만 19세 이상 대상입니다.

## 실행 방법

1. [Node.js](https://nodejs.org)를 설치합니다.
2. 이 폴더에서 아래 명령을 실행합니다.

```bash
node server.js
```

3. 브라우저에서 `http://localhost:8765` 를 엽니다.

서버 없이 `sulsul/index.html` 파일을 더블클릭해도 열립니다.

`sulsul/img/` 폴더에 사진을 넣으면 병 그림 대신 사진이 보입니다. 사진이 없으면 그림으로 대신 표시됩니다.
