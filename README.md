# 술술 첫잔

술을 처음 만나는 사람을 위한 **술 안내 사이트 데모**입니다. 5문항 퀴즈(어울리는 술 스타일과 제품 이름 추천), 술 타로, 칵테일 16종, 술 종류 12종, 세부 종류 28개별 실제 판매 제품 52개, 낮/밤 화면이 들어 있습니다.

> 이 사이트는 술을 판매하지 않고 고르는 법만 안내합니다. 제품명·도수·용량은 2026년 11월 판매 페이지 기준의 참고 정보이며 실제와 다를 수 있습니다. 결제와 주문 기능은 없습니다. 만 19세 이상 대상입니다.

## 실행 방법

1. [Node.js](https://nodejs.org)를 설치합니다.
2. 이 폴더에서 아래 명령을 실행합니다.

```bash
node server.js
```

3. 브라우저에서 `http://localhost:8765` 를 엽니다.

서버 없이 `sulsul/index.html` 파일을 더블클릭해도 열립니다.
